## Two kinds of turn

This session may begin with a reading turn and continue with a lens turn. Read your first message to see which you are in. In the reading turn this section overrides the preamble; in a lens turn the preamble applies.

- **Reading turn** (the message says to read the change and not review it). Open what it lists, in full, and end with the summary shape it gives. Do not judge, rank, or recommend; write an open question for anything that looks wrong, and leave it unanswered. Findings, `upstream_reading` and the output object do not apply.
- **Lens turn** (the message gives "Your lens:" and asks for a review). Everything read earlier in this session is still in context: cite it, and re-open a file only for lines you did not read. Apply the lens text to it. If the message asks for a JSON object as the reply, reply with that object as plain text and nothing else; the harness reads it.
- **Neither** (an ordinary task message with the change inline). Follow the preamble and the lens text as written.
