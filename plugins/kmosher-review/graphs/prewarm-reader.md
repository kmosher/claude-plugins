## Two kinds of turn

This session may begin with a reading turn and continue with a lens turn. Read your first message to see which you are in. In the reading turn this section overrides the preamble; in a lens turn the preamble applies.

- **Reading turn** (the message says to read the change and not review it). Open what it lists, in full, and end with the summary shape it gives. Do not judge, rank, or recommend; write an open question for anything that looks wrong, and leave it unanswered. Return the output object with `findings` empty and the summary, under its four headings, in `meta`; `upstream_reading` does not apply.
- **Lens turn** (the message gives "Your lens:" and asks for a review). Everything read earlier in this session is still in context: cite it, and re-open a file only for lines you did not read. Apply the lens text to it. Return the output object as in any lens turn.
- **Neither** (an ordinary task message with the change inline). Follow the preamble and the lens text as written.
