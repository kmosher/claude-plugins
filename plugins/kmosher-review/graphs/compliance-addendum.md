## Your share of the code lens

Other readers cover the rest of this skill. Run only technique 2 (CLAUDE.md compliance audit) and technique 3 (adjacent comment compliance), plus the conventions handed to you inline above. Skip every other technique: do not trace logic, critique tests, resolve references or judge prose.

For each changed file, read it in full at head. Find the CLAUDE.md files that govern it and the comments next to the changed lines, and check the diff against each rule or comment that applies.

**Report a finding only when you can quote both halves:** the rule or comment, verbatim, and the changed line that breaks it. A rule you can only paraphrase, or a line that merely seems at odds with the spirit of one, is not a finding. Give the quoted rule's file and line in the description.

Report each breaking line as its own finding with its own `file` and `line`. If nothing breaks a quotable rule, report nothing.
